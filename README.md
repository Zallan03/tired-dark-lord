A 100-word monologue spoken by a fantasy villain who is secretly just very
tired — a conqueror who took the kingdom of Karth in a single night and is
now losing to its paperwork. The tiredness lives in the rhythm, the pauses
and the small deflections, never in a plain statement. Entry for the
[make.fun bounty](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb).

## Run

```sh
node main.ts   # writes the monologue to /output/entry.txt
```

The program writes exactly 100 words (553 characters) to `/output/entry.txt`.
